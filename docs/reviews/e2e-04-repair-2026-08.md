## 발견 목록

### FAIL

1. **수선 결제 성공 URL 새로고침이 완료 상태를 복원하지 못함**
   - 재현: `이미 발송했어요`로 송장·사진을 입력해 수선 결제 완료 → `발송 정보까지 등록되었습니다` 확인 → 같은 success URL 새로고침.
   - 기대: 이미 제출된 주문·발송 정보를 조회해 동일한 완료 화면을 표시하고 재제출하지 않음.
   - 실제: `결제를 확인하지 못했습니다` 화면으로 전환. API의 중복 `/payments/confirm`은 `409 Conflict`를 반환했다.
   - 영향: 결제와 발송 등록은 성공했지만 고객에게 실패처럼 보여 재시도·문의·중복 행동을 유발할 수 있다.

2. **사진 업로드 중 입력한 발송 메모가 업로드 완료 시 소실됨**
   - 재현: 주문서에서 `이미 발송했어요` 선택 → 송장 입력 → 발송 사진 업로드 직후 업로드 중 상태에서 메모 입력 → 업로드 완료.
   - 기대: 비동기 사진 업로드와 무관하게 입력 중인 메모를 보존하고 발송 접수에 저장.
   - 실제: 업로드 완료 렌더 뒤 메모 입력값이 공백으로 초기화됐다. `ORD-20260811-007` receipt는 사진 1장이 저장됐지만 `memo`·`reason`은 null이고 admin 카드에도 없다.
   - 영향: 고객이 남긴 발송·입고 확인 맥락이 조용히 유실될 수 있다.
