## 판정

> 후속 구현에서 최대 6색 규칙은 폐기했다. 현재 계약은 생성 prompt로 그라데이션·음영을
> 금지하고, 양자화는 가까운 중간색만 정리하며 팔레트 크기는 모티프에 따라 가변이다.
> 아래 6색 내용은 파일럿 당시의 실험 기록이다.

**통과.** 런타임 전환안은 Recraft 제거 후 **GPT Image 2 quality=low + 로컬
VTracer medium**으로 확정한다. 여기서 low는 유료 이미지 생성 품질이고 medium은
비용 없는 로컬 곡선 단순화 단계다. 실제 resolver·설정·DB·문서 전환은 이번 파일럿
범위에 포함하지 않았다.

## 교정과 무과금 재검증

- 투명 픽셀의 숨은 RGB를 팔레트 계산에서 제외해 **보이는 전경에 최대 6색을 전부
  배정**한다. 정확히 6색을 강제하는 규칙은 아니다.
- VTracer가 만든 근사색은 이미 계산된 전경 팔레트의 가장 가까운 색으로 되돌려
  `color_count` 계약을 실제 SVG에도 유지한다.
- 생성 프롬프트에 사방 최소 10% 안전 여백을 명시하고, 트레이스 SVG에 투명 논리
  프레임을 남겨 정규화가 원본 캔버스 여백을 잘라내지 않게 했다. x/y 기하 비율뿐
  아니라 캔버스 안의 크기·여백 비율도 유지한다.
- 평가 갤러리의 회색은 이미지 배경이 아니라 CSS였으므로 흰색으로 수정했다.
- 저장된 첫 GPT PNG 20개를 외부 API 호출 없이 재처리한 결과:
  - VTracer low: 20/20, 최대 path 예산 71.78%.
  - VTracer medium: 20/20, 최대 node 8.35%, path 16.50%, command 4.11%,
    SVG bytes 3.57%.
- low와 medium의 육안 차이는 미미했고 medium의 복잡도 여유가 훨씬 커서 medium을
  기본값으로 선택했다.
