# E2E 01 스토어 후속 수정 결과 — 2026-08-11

## 결과

- 시드 상품을 4개 카테고리의 14개 조합으로 확대했다. 기존 `3F-SEED-001`,
  `KN-SEED-001` 코드는 유지했고 `3F-SEED-002`에는 재고 3개 옵션을 추가했다.
- 모든 시드 상품에 fake GCS 대표 PNG와 `product_primary` `Image` 연결을 만들었다.
  기존 상품도 연결이 없으면 재시드만으로 백필되며, 상품 URL은 `public_asset_url`로
  정규화된다.
- 후기 가능 상태를 `완료`로 제한했다. 배송완료·제작완료·수선완료에서는 주문 액션과
  후기 생성 API가 모두 후기를 허용하지 않는다.
- API 스키마는 바뀌지 않아 api-client 재생성은 하지 않았다.

- DB/API: 시드 상품 14개, 활성 대표 이미지 연결 14개, 인기 조회 4개,
  `3F-SEED-002` 일반 옵션 재고 3개.
