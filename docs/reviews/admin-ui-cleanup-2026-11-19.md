# 관리자 UI 정리·문구 정리 — 실행 기록 (2026-11-19)

플랜 `docs/plans/admin-ui-cleanup.md`와 `docs/plans/admin-ui-copy.md`(둘 다 삭제)를 실행했다. 관리자를 휴대폰(390px)에서
쓰기 불편하다는 운영자 피드백에서 시작했고, 화면 문구 전체(2,103줄)를 검토해 함께 정리했다.

## 한 일

- **safe area** — `apps/admin/index.html`에 `viewport-fit=cover`. 저장 바(`EditModeShell`)와 `main` 하단에
  `env(safe-area-inset-bottom)`을 더했다.
- **탭 넘침** — 390px 견적 상세 탭 폭 438px > 358px로 실제 넘침을 확인했다. shared `TabList`를 `ScrollFog`로 감싸 가로
  스크롤하고, 선택 탭을 보이게 옮긴다. 스크롤 컨테이너가 border를 잘라 밑줄은 inset 그림자로 그린다(스토어 공용).
- **카드 이중 구조** — 목록 표 카드 제목 제거(12곳). `AdminCard`는 md 미만에서 카드 틀 없이 섹션으로, 모바일 셸 바탕은
  `bg.layer-default`. PC는 그대로.
- **머리 줄** — `RouteHeading`에 `backTo`(제목 위 "‹ 목록 이름" 링크)·`badges`·`actions`. "목록으로"·"상세로" 버튼 17곳을
  링크로 바꾸고 `back-to-list-button.tsx`를 지웠다. 규칙은 `apps/admin/AGENTS.md` 앱 셸 절.
- **새로고침 버튼 전부 제거**(운영자 결정) — 목록 12곳·대시보드·고객 상세·팝업·템플릿·생성 로그 상세. 표 오류의
  "다시 시도"는 `onRetry`로 남겼다.
- **로딩** — 설정·가격·고객 상세·주문 상세의 "불러오고 있습니다" 문구를 `PageSkeleton`(새 `shared/ui/page-skeleton.tsx`)으로.
- **검색 초기화** — 상품 목록은 적용 필터 칩으로 충분해 버튼 삭제. `SubmittedMemorySearch`는 입력창 안 ✕(aria-label 유지).
- **표시 버그** — 클레임 상세 상태 원값, 문의 상태·카테고리, 무늬 범위·출처, 대시보드 연동 모드(`real`·`dry_run`),
  이미지 MIME 원값을 한글·확장자로.
- **문구** — 부연 설명 삭제, 용어 통일, 오류 문구에 해결 행동, 맞춤법. 운영자 결정:
  거부→**거절**(admin·스토어 마이페이지·shared `claimBadge`, DB 값은 "거부" 유지), **일반 주문**, **수기 주문**
  ("작업지시서"는 이미지 저장 기능에만), **3폴드·7폴드**, **디자인 생성 로그**, 수기 주문 "확인"→**발송 완료**
  (제작·수선 후 택배 발송까지 끝남 — `commerce.py` 주석·`docs/api-spec/domains.md`에 기록, 스키마 그대로),
  "대사"→**토스 결제 상태 반영**(api 액션 라벨·결제 오류 메시지·결제 이상 차단 사유 포함, 결제 로직 무변경).
  스토어 결제 실패 화면은 서버 메시지를 쓰지 않아 고객 노출 없음을 확인했다.

## 하지 않은 것

- **버튼 최대 2개 + "더보기"** — 운영자가 기각. 자주 쓰는 버튼(상태 변경, 작업지시서 이미지 저장)은 그대로 둔다.
  390px 주문 상세 버튼은 3줄 → 2줄.
- **저장 바 모바일 압축** — 390px에서 한 줄에 들어가 건너뛰었다. 긴 상태 문구("저장하지 않은 변경이 있습니다")에서
  두 줄로 접히면 재론.
- **작업지시서 캡처 모양 통일** — PC 저장은 카드 모양, 휴대폰 저장은 카드 없는 모양. 운영자가 그대로 두기로 했다.
- 로그인 흐름 세션 오류 문구, `router.tsx`·`private-asset-preview.tsx`의 로딩 문구(형태 없는 대기)는 그대로.
