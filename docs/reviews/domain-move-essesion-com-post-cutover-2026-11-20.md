# essesion.com 이전 — 전환 뒤 확인 결과 (2026-11-20)

`docs/plans/domain-move-essesion-com.md`의 D(전환 뒤 확인) 전부를 실행했다. `.shop`의 화면 주소는 이제 301로
넘어오고, 검색 콘솔 두 곳에 `.com`이 등록됐다. 남은 일은 플랜의 E(정리)다.

## 한 일

- **브라우저 실측**(운영자): `.com`에서 소셜 로그인 4종, 실결제와 취소, 이미지 업로드, 상품 이미지, 알림톡, admin
  로그인이 된다. 네이버 로그인 서비스 URL도 `.com`으로 바꿨다.
- **토스 웹훅**: 2026-11-20 09:19의 부분 취소에서 `PAYMENT_STATUS_CHANGED`가 "성공"으로 전송됐다(토스 개발자센터
  전송 내역). 운영에서 받은 첫 통지다.
- **솔라피**: 2026-11-12~19의 클레임 완료·거부 알림에 실패가 없다(운영자 확인).
- **302 → 301**: 구 존 Redirect Rules 4개를 301로 바꿨다. 경로·쿼리 보존과 `http://` 요청을 curl로 확인했다.
  `api.essesion.shop`은 그대로 200이다. 구 존 HSTS는 꺼져 있다.
- **GA4**: 웹 스트림 URL을 `.com`으로 바꾸고, 원치 않는 추천에 `essesion.shop`을 넣었다. Search Console 링크는
  `.shop`을 지우고 `essesion.com` 도메인 속성으로 다시 만들었다.
- **Search Console**: `essesion.com`을 도메인 속성으로 추가하고, `.shop` 속성에서 주소 변경을 제출하고,
  `https://essesion.com/sitemap.xml`을 냈다.
- **네이버 서치어드바이저**: `https://essesion.com`을 등록했다. 소유 확인용 메타 태그를 스토어 `index.html`에
  넣었다(#122).
- **운영 DB**: 텍스트·JSON 컬럼 173개를 전부 훑어 5행을 찾았고(`order_items.item_data` 4, `inquiries.answer` 1),
  마이그레이션 `b3e7c9a41f06`으로 바꿨다(#123). 배포 뒤 다시 세어 0행이다.
- **네이버 블로그**: 글 16개 중 `.shop` 링크가 있던 12개를 `.com`으로 고쳐 다시 발행했다. 발행 뒤 전체 글에서
  `essesion.shop`이 0건이다.

## 확인한 것

- Sentry: 스토어 프로젝트의 Allowed Domains가 `*`이고, 모니터·수신 필터에 도메인 조건이 없다. 바꾼 것 없음.
- PostHog: Web analytics domains에 등록된 주소가 없고, 리플레이·자동 수집에 도메인 제한이 없다. 바꾼 것 없음.

## 플랜과 달랐던 점

- **301을 플랜보다 하루 일찍 바꿨다.** 플랜은 리다이렉트를 켠 뒤 48시간(2026-11-21)을 기다리라고 했지만,
  실측이 모두 끝나 있어 2026-11-20에 바꿨다. E의 시작일은 2026-12-04가 된다.
- **Search Console에 `.com` 속성이 없었다.** 플랜은 주소 변경만 적었는데, 속성 추가가 먼저 필요했다. 구 속성은
  도메인 속성이라 새 속성도 도메인 속성으로 맞췄다.
- **주소 변경의 첫 검사가 실패했다.** `http://essesion.shop/`을 "가져올 수 없습니다"로 두 번 실패한 뒤 URL 검사의
  실제 URL 테스트를 한 번 돌리자 통과했다. curl로는 처음부터 301이었다 — 301로 바꾼 직후의 구글 쪽 일시
  오류로 본다(추정).
- **DB의 남은 행은 마이그레이션 대상 밖 컬럼에 있었다.** 주문 시점 상품 사본(`item_data`)에 이미지의 절대 URL이
  함께 들어간다. 호스트를 다시 옮길 일이 생기면 이 컬럼도 대상이다.
- **네이버 블로그는 플랜에 없었다.** 코드 밖에서 `.shop`을 가리키던 유일한 곳이다(운영자 확인).
- **cloud-sql-proxy와 tofu 인증**: 이 머신에 프록시가 없어 새로 설치했고, 기본 자격 증명(ADC)이 다른 계정이라
  `--gcloud-auth`로 띄웠다. 연결 이름은 `gcloud sql instances list`로 얻었다.

- 네이버 서치어드바이저 사이트맵 제출 여부.
- 블로그 글의 모바일 화면.
