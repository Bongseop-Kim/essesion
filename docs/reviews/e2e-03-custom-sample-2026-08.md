## 발견 목록

### FAIL

1. **비로그인 주문제작 초안이 로그인 뒤 복원되지 않음**
   - 재현: 비로그인 `/custom-order`에서 폭·메모 입력 → 파일 선택 또는 주문 제출로 로그인 다이얼로그 → 로컬 고객 로그인.
   - 기대: 주문제작 화면으로 복귀하고 익명 초안을 사용자 초안으로 이관. 첨부가 있었다면 재첨부 안내 표시.
   - 실제: 로그인 뒤 홈으로 이동. `/custom-order` 재진입 시 사용자용 빈 초안이 우선되고 익명 초안은 별도 키에 남아 폭·메모가 복원되지 않음.
   - 영향: 로그인 전 작성한 주문 사양을 고객이 다시 입력해야 한다. 첨부 파일은 로그인 차단 시점에 저장되지 않았다.
