## 발견 목록

### FAIL

1. **관리자 상품 상세 조회 409 — 배포 차단**
   - 재현: admin `/products` → 시드 상품 선택.
   - 기대: 상품 상세와 옵션 재고 편집 화면 표시.
   - 실제: `상품을 불러오지 못했습니다`; API 로그에서 `GET /admin/products/1`이 반복해서 `409 Conflict`.
   - 영향: 운영자의 상품·재고 편집과 S3 품절 분기 전체가 차단된다. 브라우저 console/pageerror는 0건이다.

2. **홈 인기 상품 수 부족 — 후속 수정**
   - 재현: store `/` → 인기 상품 섹션.
   - 기대: 클릭 가능한 인기 상품 4개.
   - 실제: 게시된 시드 상품 2개만 표시. 상세 이동 자체는 정상이다.
   - 영향: 홈 콘텐츠 요구사항과 시드 전제가 맞지 않는다. 콘솔/API 오류는 없다.

3. **구매확정 전 후기 버튼 노출 — 후속 수정**
   - 재현: 클레임 없는 주문을 admin에서 배송완료로 전환 → store 주문 상세 새로고침.
   - 기대: 구매확정 뒤 `후기 작성` 노출.
   - 실제: 배송완료 단계부터 후기 버튼이 표시되고, 구매확정 후에도 표시된다.
   - 영향: 구매확정 전 후기 작성 진입을 허용할 수 있다. 구매확정 다이얼로그와 확정 후 클레임 액션 소멸은 정상이다.

### WARN

1. **시드/상태 부족으로 일부 표시 분기 미검증 — 관찰**
   - S1의 12개 초과 목록, S2의 재고 5개 이하, S6의 `확인 필요` 항목 제외, S16의 데이터가 있는 필터별 빈 상태, SA7의 결제 이상 상세는 현재 로컬 데이터로 만들 수 없거나 별도 이상 결제가 필요해 실행하지 않았다.

2. **클레임 차단 툴팁 미검증 — 관찰**
   - SA2 상태 변경의 인라인 차단 사유는 확인했으나 클레임 차단 사유 툴팁은 별도로 재현하지 못했다. 거부·완료 처리는 정상이다.

3. **알림 인증 결합 분기 미검증 — 관찰**
   - S18에서 휴대폰 인증을 먼저 완료해 `미인증 상태에서 서비스 알림 ON` 분기를 실행하지 못했다. 인증 DRYRUN SMS와 설정 저장은 각각 정상이다.

4. **주문·클레임 Solapi 로그 없음 — 관찰**
   - 신규 주문·클레임 실행 당시 시드 고객 전화번호가 미인증이어서 수신 대상이 없었고 DRYRUN Solapi 주문/클레임 로그가 생성되지 않았다. 인증 뒤 수행한 시드 주문의 진행중 전환·롤백도 알림 로그를 만들지 않아 주문·클레임 알림 경로 자체는 검증하지 못했다. S18 본인인증 SMS 로그는 1건 확인했다.
