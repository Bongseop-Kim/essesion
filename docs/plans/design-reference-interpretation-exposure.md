# 참고 사진 해석 내용을 턴 이력에 노출

> `docs/plans/design-reference-text-precedence.md` 결정 2에서 분리 (2026-07-30).
> 리뷰 U8(`docs/reviews/design-input-modality-e2e-2026-07-30.md`) 해결을 겸한다.

## 문제

- 사진이 항상 모델에 전달되고 텍스트가 명시하지 않은 축은 사진이 채우는데, 모델이
  사진에서 무엇을 읽었는지("스트라이프 + 벌") 사용자가 볼 수 없다. 결과가 이상해도
  원인을 알 수 없고 텍스트로 교정할 수도 없다.
- U8 **[실측]**: "자동 판단"이 실제로 무엇을 골랐는지 고객·관리자 어디에도 표시되지
  않는다 — 로그의 `input_type`·`motifs[].source`로만 사후 확인 가능
  (`turn-feed.tsx:266-271`).

## 방향 (스텁 — 착수 시 구체화)

- worker가 플랜에 사진 해석 요약(무엇을 모티프·색·구도로 읽었는지)을 담아 반환하고,
  api 응답 스키마를 거쳐 store 턴 이력(`turn-feed.tsx`)에 표시한다.
- api 스펙이 바뀌므로 `pnpm codegen` 후 api-client를 같은 커밋에.
- 선행: text-precedence 플랜 완료 후 착수 (해석·우선순위 동작이 먼저 확정돼야
  노출 문구가 정해진다).
