# E2E 04 — 수선 (Aside) — 실행 지시서

4부작의 4편. 리폼 주문서 → 발송 방법 분기 → 발송 등록 3경로 → admin 상태 머신 →
구매확정·후기까지. 다른 플랜과 독립적으로 실행 가능.

수선 상태 머신(서버):
`발송대기 →(송장 등록) 발송중 / →(송장 없이) 발송확인중`, 수거 신청 시 `수거예정`.
이후 admin이 `접수 → 수선중 → 수선완료 → 배송중 → 배송완료 → 완료`.

## 공통 전제

`e2e-01-store.md`의 공통 전제와 동일. 결과 기록·후속은 같은 문서의 **"결과 기록과 후속"**
절을 따른다 — 결과 문서는 `docs/reviews/e2e-04-repair-2026-08.md`. 순수 검증 로직(사진
10MB·타입, planRepairOutcome 등)은 유닛 테스트가 커버하므로 E2E에서 반복하지 않는다.

수선 주문이 4건 생긴다(R6·R7·R8·R9) — 전부 mock 결제라 비용 없음. 사진은
`apps/store/public/logo/logo.png` 재사용.

## reform 주문서

| ID | 단계 | 확인 |
|---|---|---|
| R1 | 넥타이 추가 모달 검증 | 서비스 0개 → 에러, 자동 수선 on+키 미입력 → 에러, 폭 수선 on+폭 미입력 → 에러. **끈(string) 선택 시 돌려묶기 체크박스 자체가 사라짐** |
| R2 | 사진 필수 | 사진 없이 제출 → 필드 에러 + 해당 항목 스크롤·포커스 + "사진을 확인해 주세요" 스낵바 |
| R3 | 일괄 적용·삭제 | 항목 2개 선택 → 일괄 적용 "N개 항목에…" 스낵바(설정 교체), 선택 삭제 다이얼로그. 배송비는 선택 1개 이상일 때만 사이드바에 부과 |
| R4 | 장바구니 경유 | 담기 → `/cart`에서 "수선 옵션 변경" 모달(사진·쿠폰 유지된 채 옵션만 변경) → 주문 진행 |
| R5 | 바로주문 | 리폼에서 "바로주문" → 주문서 직행, 수선 항목에 "수선" 뱃지·서비스 요약 |

## 발송 방법 분기와 등록 3경로 (각각 별도 주문)

| ID | 단계 | 확인 |
|---|---|---|
| R6 | **방문 수거** | 주문서에서 "방문 수거"(+수거비 행) → "배송지와 같은 주소" 해제 → 수거지 폼 검증(공백이면 결제 disabled + helperText) → 입력 → 결제(mock) → success "방문 수거 신청이 완료되었습니다" → 주문 상태 `수거예정`·상세에 수거 안내 박스+수거 요청 섹션 → `/repair-shipping` URL 직접 진입 시 상세로 리다이렉트 |
| R7 | **직접 발송 + 사전 입력** | "이미 발송했어요" 체크 → 택배사만 선택 → "송장번호를 입력해 주세요"(쌍 검증) → 송장·사진 입력 → 결제 → success "수선 접수가 완료되었습니다"(자동 등록) → 상태 `발송중`, 상세 "고객 발송 접수" 카드에 송장·사진 |
| R8 | **직접 발송 + 미입력** | 체크 없이 결제 → success "발송 확인하기" CTA → repair-shipping(발송 확인 체크 자동) → **빈 폼(순수 발송 확인)도 유효** → 제출 → 상태 `발송확인중` |
| R9 | **주문 상세에서 등록** | 미입력 결제 후 success를 떠남 → 주문 상세의 입고 주소 카드("주소 복사" 클립보드)+발송 정보 등록 버튼 → 폼 제출(송장 포함) → `발송중`. 등록 후 재진입 시 상세로 리다이렉트(발송대기 가드) |
| R10 | success 멱등 | R7 success 새로고침 → "발송 정보까지 등록되었습니다"(submitted) 화면, 재제출 없음 |

## admin 상태 머신·마무리

| ID | 단계 | 확인 |
|---|---|---|
| RA1 | 진행 | R7 주문: `접수 상태로 진행` → 수선중 → 수선완료 → 배송중 → 배송완료. 각 단계 store 상태 뱃지 tone 반영 |
| RA2 | 롤백 | 수선중→접수 롤백 1회: **메모 3자 미만 에러** → 입력 → 확인 다이얼로그 → 성공 → 재진행 |
| RA3 | 업체 발송 정보 | 배송중 전환 시 "송장 정보 수정"으로 회사 택배사·송장 입력 → store 상세 "업체 발송 정보" 표시 + 배송조회 새 탭 버튼(지원 택배사 코드일 때) |
| RA4 | 수선 조회 카드 | R6 주문의 수거 요청 카드, R7 주문의 발송 접수 카드(사유·메모·사진 서명 URL) |
| R11 | 구매확정·후기 | 배송완료 주문 구매확정 → 클레임 액션 소멸 → **주문 단위** 후기 작성("서비스 후기") → "작성한 후기 보기" 전환 → admin reviews에 표시 |
| R12 | 수선 클레임 | R8 주문(`발송확인중` — 취소 가능 상태 집합에 포함)에서 취소 신청 → admin 처리 → store 반영 |
