# 디자인 페이지 재설계 — 총괄

목표 화면(확정): <https://claude.ai/code/artifact/a6d6ae6b-92ba-4e49-907f-cebc97ea8bf7>

후보(candidate) 개념을 없애고 **하나의 디자인을 문장으로 계속 고쳐 올리는 스택 편집**으로
바꾼다. 입력창은 색·줄무늬·배치·크기만 담당하고, 모티프는 별도 모달에서 문장으로 찾거나
만든다. 화면은 풀블리드 캔버스 + 좌측 모티프 패널 + 우측 아이콘 레일 + 하단 이력·입력창.

## 작업 원칙 (이번 재설계 전체에 적용)

- **레거시 없음.** 후보·패턴 설정·전체 재저작(refine)처럼 대체되는 개념은 코드·스키마·
  문서·테스트·정책에서 **삭제**한다. 플래그로 남기거나 deprecated 주석으로 남기지 않는다.
- **미사용 즉시 삭제.** 이 재설계로 참조가 끊기는 컴포넌트·훅·엔드포인트·필드·스펙 문서는
  같은 단계에서 지운다. "나중에 쓸지도"는 근거가 아니다.
- **데이터도 삭제.** 존재 이유가 없어지는 데이터(후보 배열이 담긴 턴 payload 등)는 남기지
  않는다. 단일 베이스라인(`db/migrations/versions/20260722_dadd999bf858_baseline.py`)은
  **미배포**이므로 새 마이그레이션을 쌓지 말고 베이스라인을 직접 고치고 로컬 DB를 다시 만든다.
- **롤백 대비 없음.** 호환 계층·이중 경로를 만들지 않는다. 결과가 나쁘면 브랜치를 버린다.
- 단계마다 브랜치를 따고, 단계 끝에서 검사 명령 전체가 통과해야 다음 단계로 넘어간다.

## 확정된 결정

| 주제 | 결정 |
|---|---|
| 되돌리기 | 이력 썸네일 클릭 = **편집 포인터 이동**. 이후 스텝(5·6·7)은 **그대로 남고**, 그 상태에서 지시하면 번호가 이어붙는다(8). 분기 트리 UI 없음 |
| 되돌리기 버튼 | 없음. 이력 클릭이 유일한 경로 |
| 입력창 역할 | 색·줄무늬·배치·크기(구성). 모티프 정체성은 타입상 불가 |
| 모티프 진입 | 좌측 패널의 슬롯 2개(썸네일 + 이름 + 편집). 진입 버튼에 가격 표기 없음 — 검색·교체는 무료, 생성만 5토큰 |
| 범위 밖 지시 | 상단 알림 1줄 + 입력창 문장 **전체 선택 하이라이트** 유지. 이력에 스텝을 남기지 않음. 버튼 없음 |
| 안내 위치 | 전부 상단 중앙 플로팅(absolute) — 캔버스·이력·입력창을 밀지 않는다. 톤 2종(자동 조정=노랑, 거절=빨강) |
| 액션 위치 | 내려받기·실사화는 우측 레일 왼쪽 열, 도구와 동일한 원형 아이콘 + 라벨 |
| `+` 버튼 | 폐기. PC·모바일 모두 도구를 레일에 전부 노출 |
| 패턴 설정 | 폐기 |
| 잔액 | 우상단 토큰 pill(클릭 시 상세) |
