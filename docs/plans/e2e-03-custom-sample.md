# E2E 03 — 주문제작·샘플·견적 (Aside) — 실행 지시서

4부작의 3편. custom-order의 이원 경로(즉시 결제 vs 견적), sample-order, admin 견적 처리,
수기 주문. **Q7(디자인 연동)은 `e2e-02`의 D13 완성본이 선행 조건.**

주의: **견적 → 결제 전환 경로는 제품에 없다**(설계상 오프라인 연락 경유). admin이 `확정`해도
store 견적 상세는 읽기 전용 — "결제 버튼이 없음"이 PASS 조건이다.

## 공통 전제

`e2e-01-store.md`의 공통 전제와 동일. 결과 기록·후속은 같은 문서의 **"결과 기록과 후속"**
절을 따른다 — 결과 문서는 `docs/reviews/e2e-03-custom-sample-2026-08.md`.
비로그인 검증(Q3)은 별도 시크릿 컨텍스트 탭.

## custom-order 시나리오

| ID | 단계 | 확인 |
|---|---|---|
| Q0 | 폼 분기 | 원단 직접 제공 체크 → 원단 조합 섹션 소멸 + 재주문 disabled·옵션 리셋. 자동→수동 타이 전환 → 딤플·돌려묶기 강제 해제 + 스낵바. 넥타이 폭: 빈 값 blur → 인라인 에러, 6.3 입력 → 6.5로 0.5 단위 스냅 |
| Q1 | 수량 100 전이 | 99→100 순간 "100개 이상은 견적 요청으로 접수됩니다" 스낵바 1회, 견적 연락처 폼·배송지 카드 노출, CTA "견적 요청하기"로 전환. 99로 되돌리면 "N원 주문하기" 복귀 |
| Q2 | draft 복원 | 옵션 입력 후 새로고침 → 옵션·연락처 복원(sessionStorage), **파일 첨부는 복원 안 됨이 정상** |
| Q3 | 비로그인 제출 (시크릿 탭) | 파일 첨부 클릭부터 로그인 다이얼로그 차단. 제출 시도 → 다이얼로그 + (첨부 있으면) "로그인 후 참고 이미지를 다시 첨부해 주세요" 스낵바 → 로그인 복귀 시 draft 복원 |
| Q4 | **즉시 결제 (<100)** | 파일 1개 첨부 → 제출 → `/order/custom-payment`(사양 요약 4행·참고 이미지 N개·쿠폰·배송지) → 결제(mock) → success → 주문 상세. **success 후 custom-order 재진입 시 draft 비어 있음**(삭제 확인) |
| Q5 | 결제 페이지 직접 진입 | `/order/custom-payment` URL 직접 → `/custom-order`로 리다이렉트 (sample도 동일) |
| Q6 | **견적 요청 (≥100)** | 검증(담당자 성함 공백 → 에러·스크롤·포커스) → 확인 다이얼로그 → 접수 스낵바 → `/my-page/quote-request` 목록. 상세: 견적 금액 "검토 중", 액션은 "목록으로"뿐(**결제·취소 버튼 없음이 정상**) |
| Q7 | 디자인 연동 (e2e-02 D13 선행) | 디자인 완성본 목록 "주문" → `/custom-order`에 디자인 1건 선택 프리필, 파일은 4개까지(합산 5 제한), 제거 시 디자인 해제 → Q4 패턴으로 결제까지 |

## sample-order 시나리오

| ID | 단계 | 확인 |
|---|---|---|
| Q8 | 샘플 유형 분기 | `봉제 샘플` 선택 → 원단 조합 섹션 숨김. `원단+봉제`로 전환 → 금액 표시 → 결제(mock) → success |

## admin 시나리오

| ID | 화면 | 확인 |
|---|---|---|
| QA1 | quote-requests 목록 | Q6 요청 표시, 검색(견적번호 2자 이상), 상태·기간 필터 시트(적용/취소 롤백), 정렬 |
| QA2 | 견적 상태 전이 | `요청→견적발송`: 금액 없이 시도 → "견적발송 전 견적 금액을 입력해 주세요" → 금액·조건 입력 → 확인 다이얼로그(diff 표시) → 성공. `견적발송→협의중→확정` 순서 진행. **확정에서는 전이 버튼 전부 비활성** |
| QA3 | store 반영 | 각 전이 후 store 견적 상세에서 상태 뱃지·견적 금액·조건 반영 확인 |
| QA4 | 상세 탭 | 요약(배송지 스냅샷)·제작 사양(한글 라벨)·견적 제안·참고 이미지(버튼 클릭 시 서명 URL 로드)·이력(전이 기록 누적) |
| QA5 | manual-orders | 등록 폼 검증: 수선 대분류 미선택 에러, **끈 선택 시 돌려묶기 disabled**, 자동수선 총장 필수 → 등록 → 수정 → 삭제(criticalSolid 다이얼로그). 견적·주문과 연결 없는 독립 장부임을 확인 |
