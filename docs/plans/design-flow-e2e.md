# 디자인 플로우 전체 E2E (Aside) — 실행 지시서

store `/design`의 전 경로와 그에 연결된 admin 화면을 한 번에 훑는다. 유료 외부 호출인
Recraft 모티프 생성은 **전 시나리오에서 정확히 1회**만 쓰고, OpenAI LLM·임베딩 호출은
제한하지 않는다.

디자인 패밀리(스트라이프+모티프·스캐터·격자 등 few-shot 25 예시) 재현 검증은 이 플랜이 아니라
`design-family-coverage-eval.md`가 담당한다 — 여기서는 대표 3건만 육안으로 본다.

환경 준비(DB 재생성 → 마이그레이션 → 전체 시드 → 임베딩 인덱싱 → 확인)는 2026-08-04에
완료했다. 시드 계정은 `customer@local` / `admin@local`(비밀번호는 `.claude/skills/aside-browser`).

## 1. 비용 통제

| 경로 | 외부 호출 | 정책 |
|---|---|---|
| 프롬프트 첫 생성 / 구성 수정 | OpenAI LLM(저작) + 임베딩(모티프 grounding) | 자유 |
| 아이디어 제안 | OpenAI LLM | 자유 |
| 모티프 탐색 | 임베딩 1회 | 자유 |
| **모티프 AI 생성** | **Recraft 1콜** + LLM spec | **전체에서 1회. 실패해도 재시도 금지** |
| 글자 넣기 / 사진에서 따오기 / SVG 올리기 / 모티프 적용 | 없음(로컬) | 자유 |
| 내려받기 · 실사화 | 없음(로컬 렌더) | 자유 |

- 세션당 Recraft 예산은 3(`design_recraft_budget`)이고 실패·카탈로그 재사용이면 예산이 환급된다.
  즉 UI가 "더 만들 수 없어요"로 막아주지 않으므로 **클릭 횟수를 사람이 통제해야 한다.**
- 해석 래더가 카탈로그를 재사용하면 Recraft를 아예 호출하지 않는다. 실제 호출을 타려면 시드
  카탈로그의 70개 subject(anchor·bee·whale·ship… 영문 동물·사물)에 없는 소재를 써야 한다 →
  **`재봉틀`을 사용**(과거 검증에서 Recraft 신규 생성 확인된 소재).
- 토큰 회계: 초기 지급 30, 첫 생성 5, 구성 수정 2, 모티프 적용·실사화·내려받기 0. 아래 시나리오
  총소모는 약 11~13이라 충분하다. 소진되면 `/token/purchase`(Toss DryRun) 또는 재시드.

## 2. store 시나리오

각 단계는 Aside `mcp__aside__repl`로 진행하고 `snapshot(page)`를 기본 확인 수단으로 쓴다.
탭을 연 직후 console·pageerror 리스너를 붙이고, 마지막에 수집 결과가 0건인지 확인한다.
스크린샷은 레이아웃·SVG 결과 육안 확인이 필요한 단계(S2·S9·S13)에서만 쓴다.

| ID | 단계 | 확인 |
|---|---|---|
| S0 | 비로그인으로 `/design` 진입 | 첫 진입 갤러리 6건, 토큰 pill placeholder, 액션 클릭 시 로그인 확인 다이얼로그(→`/login` 직행 아님) |
| S1 | `customer@local` 로그인 후 재진입 | 온보딩 다이얼로그 표시 → 닫으면 재진입 시 안 뜸, 토큰 pill 30 |
| S2 | 갤러리 예시로 시작 | "토큰은 쓰지 않았어요" 스낵바, 캔버스 SVG 렌더, 타이↔평면 토글 전환 |
| S3 | 새로 시작 → 프롬프트 첫 생성 ("굵은 대각선 줄무늬와 작은 원형 모티프가 어우러진 디자인" = `stripe_motif`) | SVG 갱신, 이력 카드 증가, 잔액 30→25 |
| S3b | 새 세션 2건으로 패밀리 대표 확인 — "크림색 배경에 동백꽃을 듬성듬성 배치" (`scatter`), "잔잔한 네이비 페이즐리를 작은 격자로 반복" (`lattice`) | 각각 흩뿌림·격자 배치가 캔버스에 보이는지 스크린샷 1장씩. 나머지 패밀리는 `design-family-coverage-eval.md`가 담당 |
| S4 | 구성 수정 ("줄 간격을 넓혀 주세요") | 잔액 25→23, 이력 한 칸 추가, 스테퍼로 이전 스텝 되돌리기 → 이력 모달 전체 보기 |
| S5 | 슬롯1 → 탐색 "벌" | 결과 그리드, "지금 쓰는 그림" 카드 구분, 선택→적용 후 디자인 갱신(토큰 0) |
| S6 | 슬롯2 → 글자 넣기 "영선" | 글꼴(나눔고딕↔나눔명조)·굵기 변경 시 즉시 재렌더, 적용 후 내 모티프에 저장 |
| S7 | 슬롯2 → 사진에서 따오기 (`apps/store/public/logo/logo.png`) | 원본↔배경 제거 비교 표시, 경고 문구 확인, 적용 |
| S8 | 슬롯1 → SVG 올리기 (`apps/worker/tests/fixtures/recraft_samples/honeybee_top.svg`) | 모달 없이 슬롯에 진행 표시 → 스낵바 → 슬롯 교체 |
| S9 | **슬롯2 → AI 생성 "재봉틀" (Recraft 1회)** | 진행 블록 → 결과 프리뷰 + "내 모티프에 저장했어요", 남은 횟수 3→2, 적용 후 디자인 갱신. **실패 시 재시도 없이 중단·보고** |
| S10 | 프롬프트에 "고래 모티프 넣어 주세요" | 생성으로 안 가고 왼쪽 모티프 패널이 열리며 안내 스낵바(Recraft 미호출) |
| S11 | 아이디어 모달 | 제안 목록 표시 → 하나 선택 시 입력창 반영 |
| S12 | 내려받기 | PNG 다운로드 성공(파일 크기 > 0) |
| S13 | 실사화 | job 진행 → 완성본 목록에 PNG 표시, 남은 횟수 10→9 |
| S14 | 내 디자인 목록 | 세션 3개(예시·프롬프트) 나열, 전환·삭제 동작, 삭제한 세션이 현재 세션이면 빈 캔버스로 |
| S15 | 토큰 검산 | pill 잔액 = 30 − (생성 5 + 수정 2×n). admin 로그의 차감·환불과 일치 |

## 3. admin 시나리오

`admin@local`로 로그인. store 탭은 열어 둔 채 별 탭으로 진행한다(S9 결과를 오가며 본다).

| ID | 화면 | 확인 |
|---|---|---|
| A1 | 대시보드 | 차트·요약 렌더, 콘솔 오류 0 |
| A2 | `/motifs` (기본 `pending`) | S9 생성 모티프가 pending으로 노출 → 상세에서 안전 SVG 프리뷰·검토 메타 → 승인 → `approved` 필터에 이동. 승인 회수(→rejected)까지 확인 후 다시 승인 |
| A3 | 승인 반영 | 승인 직후엔 임베딩이 없다(embedding은 approved 행만 받는다) → `index_motif_embeddings.py --confirm-live` 1회 실행 후 store 탐색 "재봉틀"에 결과로 등장하는지 확인. 인덱싱 전에는 어휘 일치만 되는 점도 함께 기록 |
| A4 | `/seamless-logs` | S3·S4·S9 로그가 각각 저작/intent/모티프 생성으로 분류, 상세에 토큰 정산·경고·요청자 링크, 세션 상관 |
| A5 | `/generation-jobs` | S13 finalize job succeeded, 산출물 키·상세 표시 |
| A6 | `/design-examples` | 목록·순서 변경·게시 토글 → store 갤러리에서 즉시 반영(비게시 시 사라짐) 확인 후 원복 |
| A7 | `/few-shot-candidates`, `/few-shot-examples` | 목록 3상태 렌더(후보 없으면 빈 상태 문구), 오소링 예시 25건 목록·상세 |
| A8 | `/settings`, `/pricing` | `design_edit_cost` 2→3 수정 → store 토큰 pill·수정 차감에 반영 → 2로 원복 |
| A9 | `/customers` | customer 상세에서 토큰 잔액·사용 이력이 S15 검산과 일치 |

## 4. 중단 규칙

- Recraft 실패(502·타임아웃) → **재시도하지 않고 중단**, 오류 원문·로그 ID를 보고한 뒤 지시를 받는다.
- 저작 실패("디자인 구성을 만들지 못했어요")는 토큰 전액 환불되므로 재시도 1회까지 허용.
- 503 `missing_configuration` → 시드 누락. AGENTS.md의 시드 명령을 다시 돌린다.
- 스키마 오류(`column ... does not exist`) → 준비가 깨진 것. 이후 단계 진행 금지.

## 5. 결과 기록

`docs/reviews/design-flow-e2e-2026-08-04.md`에 ID별 판정표(PASS/WARN/FAIL + 확인 내용),
발견한 회귀·개선 관찰, 실행한 자동 검사(필요 시 `uv run pytest`·`pnpm lint`)를 남기고 이 플랜
문서를 제거한다. Recraft 실제 호출 횟수를 기록해 1회를 넘지 않았음을 명시한다.
